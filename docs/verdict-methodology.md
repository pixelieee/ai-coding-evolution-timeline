# 「从夯到拉」评级方法

核查日期：2026-11-03。

这不是模型能力榜，也不按单次 benchmark 排名。评级只回答一个问题：这个节点是否真正改变了 AI Coding 的技术路线、产品形态或行业工作方式。

## 四类证据

1. **新增机制**：提出此前没有的训练方法、交互方式、协议或执行架构。
2. **生态扩散**：被多个独立产品、厂商、开源项目或标准组织采用。
3. **真实采用**：有用户规模、生产部署、开源贡献或可复现实验，而不只是发布演示。
4. **持续性**：能力或接口被后续版本继承；短期预览、单次跑分和厂商自报不能单独证明。

## 档位

- **夯**：通常至少满足三类证据，并改变后来者的默认做法。
- **顶级**：明确推动路线跨过临界点；至少有跨生态采用或可复现实验。
- **人上人**：解决真问题且有公开结果，但外溢范围或持续时间仍有限。
- **NPC**：近期发布、研究原型、预印本，或证据主要来自发布方。
- **拉完了**：只在存在明确终止、并入、弃用或被替代记录时使用。能力一般、讨论度下降或个人不喜欢，都不构成最低档证据。

## 来源顺序

论文与会议记录、标准组织和官方仓库优先；产品采用与规模采用官方披露，并在文案中明确主体。媒体报道和社区讨论只作为线索，不单独决定档位。每张卡保留判定依据与直接链接；节点的首发时间、完整摘要和首发来源仍在详情页。

评级会随证据变化。新项目如果获得独立复现、跨平台采用或生产部署，可以上调；已有产品明确退场或原始结论无法复现，也会下调。
